# 理科教学动画 QA 契约与质量准则

面向通用理科课程动画制作，确立轻量、务实、高效的三层质量准则。

---

## 一、三层质量准则体系

```
[ Level 1: 静态与数理有效性 ] ──> 保证无语法错误、参数有限、无 NaN/Inf、符号恒等闭合
              │
[ Level 2: 屏幕几何安全检测 ] ──> 保证公式/文字 AABB 无穿模碰撞、保留底部字幕安全区
              │
[ Level 3: 视觉关键帧画册审阅 ] ──> 自动输出多镜头代表性长图画册，直观核验教学节奏与观感
```

### 1. Level 1: 静态与数理有效性
- **语法与 AST 检查**：源码合法可解析，`ValueTracker` 必须绑定 updater 或 `always_redraw`，严禁空转。
- **参数有限性**：数理参数必须为有限实数，时间尺度严格为正数，无奇异点或除零隐患。
- **符号与理论闭合**：利用 SymPy 动态验证公式残差，特征关键点数值误差在可控容差内。

### 2. Level 2: 屏幕几何安全检测
- **文字与公式碰撞**：可见文字与 MathTex 之间的逐帧 AABB 碰撞重叠必须小于阈值（2px 缓冲），禁止公式与标签穿模混叠。
- **字幕安全区**：$Y \le -3.3$ 区域留给播放器外部字幕，禁止主视觉图文侵占。
- **对象生命周期**：显式执行 `FadeOut` 或 `ReplacementTransform` 的对象在随后帧中必须正常销毁，杜绝幽灵残影。

### 3. Level 3: 视觉关键帧画册审阅
- 渲染完成后自动调用 `scripts/extract_keyframes.py`，从全片等间隔均匀采样 4~6 帧关键代表帧，拼装为画册长图 `qa/keyframes_preview.jpg`。
- 供 Agent 与用户快速检查：
  - 字形与中文字体是否清晰
  - 公式与图文是否有充足的“呼吸间距”（$\ge 0.2$ 屏幕单位）
  - 核心公式得出后是否有 2~3 秒定格留白

---

## 二、去官僚化纪律

1. **废除形式主义登记**：不再强制要求记录 `first_draft.json`、`build_history.json` 或 `checker_version.json` 快照。
2. **废除逐像素零容差对比**：教学动画追求视觉清晰与数理正确，不以逐像素哈希锁定限制正常的样式升级。
3. **零阻断即时反馈**：发现排版冲突时，输出明确的像素重叠坐标与时间戳，支持直接在代码中定向修正坐标参数，无需繁重的多轮发版仪式。
