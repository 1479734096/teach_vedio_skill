# 布局分区、字阶体系与语义调色板 (03-layout-typography-and-color.md)

本规范系统性阐释了在 1080p 全高清视频下，如何通过科学的垂直空间分区 (Zone-based Layout)、统一字阶常数体系 (Typography Scale) 与语义化色彩绑定 (Semantic Color Palette)，创造出清晰、专业、高可读性的 3Blue1Brown 风格视觉体验。

---

## 一、垂直空间分区体系 (Zone-based Layout)

在 Manim 默认的 16:9 画布中，屏幕坐标范围通常为 $X \in [-7.11, +7.11]$，$Y \in [-4.0, +4.0]$。为了避免各元素无序堆叠和上下穿模碰撞，必须将屏幕划分为 6 个标准垂直功能区：

```
+-------------------------------------------------------------+  Y = +4.0
| [Zone 1] 标题栏与场景导引 (Y = +3.3 ~ +3.7)                   |
+-------------------------------------------------------------+  Y = +3.0
| [Zone 2] 上部背景模型 / 输入条件 / 两列行波 (Y = +1.8 ~ +2.8)   |
+-------------------------------------------------------------+  Y = +1.4
| [Zone 3] 核心恒等式卡片 / 推导中介 (Y = +0.7 ~ +1.1)           |
+-------------------------------------------------------------+  Y = +0.4
| [Zone 4] 核心主角公式 (Hero Formula) 与框注 (Y = -0.3 ~ +0.3)  |
+-------------------------------------------------------------+  Y = -0.8
| [Zone 5] 顿悟结论横幅 / 说明卡片 (Y = -1.2 ~ -1.6)            |
+-------------------------------------------------------------+  Y = -2.0
| [Zone 6] 底部微缩物理动态仿真系统 (Y = -2.2 ~ -3.2)            |
+-------------------------------------------------------------+  Y = -3.3
| [Safety] 外挂字幕绝对保留区 (Y = -3.3 ~ -4.0，禁止放置主视觉)   |
+-------------------------------------------------------------+  Y = -4.0
```

### 垂直呼吸间距准则 (Breathing Margins)
- **卡片与横幅间距**：两个纵向相邻的背景卡片（如 Zone 4 的 SurroundingRectangle 说明卡与 Zone 5 的顿悟横幅）之间的垂直净距必须**大于等于 0.20 屏幕单位**。
- *A_3b1b_final 优化实证*：V2 中公式框注与下方绿色横幅上沿的垂直间隙不足 0.05 单位，造成紧迫压抑感；Final 将公式基准线上提至 `UP*0.12`，横幅下移至 `DOWN*1.36`，间隙扩展至充裕的 0.21 单位，彻底消除了视觉拥挤。

## 二、统一字阶标准 (Unified Typography Scale)

为了杜绝工程中零散硬编码的 14pt、15pt、16pt、17pt 导致的多层级凌乱，必须在 `style.py` 中统一定义并严格调用以下字阶常数：

| 常数变量名 | 字号 (pt) | 适用场景与构件 | 视距可读性标准 |
|---|---|---|---|
| `FS_TITLE` | 34 | 场景大标题（居中置顶 `to_edge(UP, buff=0.35)`） | 远屏第一视觉焦点 |
| `FS_SUBTITLE` | 22 | 标题下方的小字副标题或章节导引 | 清晰辅导层次 |
| `FS_FORMULA_HERO` | 36 | 本场景最关键的核心主角公式（如驻波方程） | 屏幕绝对视觉重心 |
| `FS_FORMULA_MAIN` | 30 | 重要的推导公式行（如入射波、反射波方程） | 一级数学表达式 |
| `FS_FORMULA_SEC` | 24 | 辅助公式、和差化积恒等式、卡片内公式 | 次级数学表达式 |
| `FS_BODY_LARGE` | 22 | 重点顿悟横幅文字、核心物理定律结论标语 | 突出强化记忆 |
| `FS_BODY_NORMAL` | 20 | 卡片正文说明、列表项、一般性解释文字 | 保证阅读舒适 |
| `FS_TAG` | 18 | 坐标轴刻度、图表角标、引线箭头说明、开路端说明 | 辅助信息底线（严禁低于 18） |

**排版铁律**：除大公式下标外，任何具有教学含义的中文字符或标注，**绝对禁止低于 18pt**。

## 三、语义化调色板规范 (Semantic Color Palette)

在科学动画中，色彩不是装饰品，而是**承载物理语义的编码符号**。一个物理量一旦绑定某种颜色，在整个视频的所有场景中必须绝对守恒！

### 1. 经典 3b1b 语义调色板定义
```python
# 背景与基底
COLOR_BG = "#0c0d11"          # 3Blue1Brown 标志性深灰纯黑底色
COLOR_LINE = "#E0E0E0"        # 机械/电路几何线架（高对比亮灰）
COLOR_AXIS = "#707070"        # 坐标轴与辅助网格（低干扰中灰）

# 物理信号与动态场（高饱和度区别色）
COLOR_INCIDENT = "#58C4DD"    # BLUE_C: 入射信号 / 正向传播 / 源激发
COLOR_REFLECTED = "#FC6255"   # RED_C: 反射信号 / 反向传播 / 边界回弹
COLOR_STANDING = "#FFFF00"    # PURE_YELLOW: 合成驻波 / 核心聚焦状态
COLOR_ENVELOPE = "#5CD0B3"    # TEAL_C: 空间振幅包络线 / 几何边界

# 特征量与顿悟标注（强提示色）
COLOR_ANTINODE = "#83C167"    # GREEN_C: 波腹 / 极大值 / 谐振相长
COLOR_NODE = "#FF8C00"        # ORANGE: 波节 / 极小值 / 零点相消
```

### 2. 颜色语义一致性检查清单
1. **数形同色**：公式中的符号颜色必须与对应图形曲线完全一致。例如，公式中的 $u_i$ 渲染为明蓝，屏幕上的入射波形也必须为明蓝。
2. **多波区分**：当两列或多列波形同时出现时，必须使用色轮上相差 $90^\circ$ 以上的高对比色（如蓝 vs 红），严禁同时使用浅蓝与深蓝混淆视听。
3. **卡片语义统一**：说明波腹的卡片边框、文字高亮及箭头必须统一使用绿色；说明波节的卡片必须统一使用橙色。
