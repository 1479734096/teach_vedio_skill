# Canvas 排版、数学符号与安全区域规范 (03-canvas-layout-and-math.md)

## 一、标准 1080p 屏幕区域划分 (LAYOUT.ZONES)

为确保视觉层级分明且杜绝遮挡，1920 × 1080 标准画布被严格划分为六大功能区域：

| 区域名称 | X 范围 | Y 范围 | 宽高 (W × H) | 用途说明 |
|---|---|---|---|---|
| **HEADER** | 80 ~ 1840 | 20 ~ 110 | 1760 × 90 | 标题区：主题标题 (左)、镜头角标 (右)、分割线 |
| **FORMULA** | 80 ~ 900 | 125 ~ 345 | 820 × 220 | 公式区：主推导公式、符号定义、波动方程 |
| **ANNOTATION**| 920 ~ 1840 | 125 ~ 345 | 920 × 220 | 解析说明区：物理机理解析、卡片要点 |
| **GRAPH** | 60 ~ 1860 | 350 ~ 790 | 1800 × 440 | 核心图形区：坐标系、连续波形、电路元件、积分区域 |
| **BOTTOM_CARD**| 200 ~ 1720| 815 ~ 907 | 1520 × 92 | 底部教学卡片：本镜核心结论与阶段性解说 |
| **SUBTITLE_SAFE**| 0 ~ 1920 | 920 ~ 1080 | 1920 × 160 | 字幕安全带：保留给外挂/烧录字幕，**严禁任何图形文字进入** |

## 二、避让间距黄金法则

1. **图形最低点 vs 底部卡片**：
   - 保持纵向间距 $\ge 80\text{px}$（推荐 $100\sim 115\text{px}$）。例如，振幅峰峰值若为 $\pm 150$px，平衡线置于 $Y_0 = 550$，波谷最低点为 $Y = 700$，卡片上沿为 $Y = 815$，避让间距达 $115$px，视觉舒适开阔。
2. **底部卡片 vs 字幕安全带**：
   - 卡片下沿为 $Y = 907$，字幕安全线上沿为 $Y = 920$，保留 $\ge 13\text{px}$ 绝对隔离间距。
3. **坐标轴标签 vs 边界标牌**：
   - 纵轴物理量标签（如 $u$ 电压）置于纵轴左侧 ($X_0 - 18$)，右侧终端标牌置于纵轴右侧 ($X_0 + 16$)，水平分离度 $\ge 30\text{px}$，彻底杜绝叠字。

## 三、数学公式排版引擎 (typesetMath)

通过 `LAYOUT.typesetMath(ctx, tokens, x, y, size, opt)` 渲染高质量数学公式，支持 Computer Modern 字体、希腊字母、斜体变量以及上下标。

### 调用示例：
```javascript
LAYOUT.typesetMath(c, [
  { s: 'u', it: true, sub: 'i', col: '#58C4DD' },
  { s: '(', gap: 4 },
  { s: 'x', it: true, gap: 4 },
  { s: ',', gap: 6 },
  { s: 't', it: true, gap: 4 },
  { s: ')', gap: 14 },
  { s: '=', gap: 14 },
  { s: 'A', it: true, gap: 10 },
  { s: 'cos', gap: 6 },
  { s: '(', gap: 4 },
  { s: 'ω', it: true, gap: 4 },
  { s: 't', it: true, gap: 8 },
  { s: '−', gap: 8 },
  { s: 'β', it: true, gap: 4 },
  { s: 'x', it: true },
  { s: ')' }
], 100, 235, 46, { align: 'left', col: '#FFFFFF' });
```

### 排版特性：
- **基线对齐**：统一采用 `alphabetic` 基线，符号与变量在同一水平线上平齐；
- **上下标自动定位**：下标垂直向下偏移 $+0.22 \times \text{size}$，上标垂直向上偏移 $-0.42 \times \text{size}$，字号缩放为 $0.62 \times \text{size}$；
- **希腊字母自动识别**：$\alpha, \beta, \omega, \pi, \lambda, \tau$ 等自动采用数理字形；
- **AABB 动态返回**：排版完成后返回该公式的实际几何包围盒 `AABB(x0, y0, x1, y1)`，供碰撞检测系统使用。

## 四、字体预热机制与零 DIFF 保证

Chromium 首次绘制某些复杂 Unicode 字符或数理符号时，会触发冷启动字形光栅化缓存填充，导致首帧与重渲染存在微小亚像素差异。
本 Skill 在 `LAYOUT.ensureFontsReady` 与 `engine.js` 启动前对常用公式字符（`0123456789+-=λμβωπΓΔφcosuiurx2At`）进行离屏预热光栅化，从根源上消除了确定性测试中的虚假 DIFF。
