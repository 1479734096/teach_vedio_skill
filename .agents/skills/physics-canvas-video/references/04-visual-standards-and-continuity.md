# 视觉规范、运动连续性与手绘材质标准 (04-visual-standards-and-continuity.md)

## 一、双主题调色体系

为保证科学严肃性与观感舒适度，本 Skill 推荐两种标准色板：

### 1. 经典 3B1B 科技黑板风 (Dark Board - 默认推荐)
- 背景底色：`#0F141D`（深黑灰蓝，低反射黑板质感）
- 卡片底色：`rgba(23, 31, 45, 0.90)`，边框 `rgba(255, 255, 255, 0.18)`
- 主物理量 (正向/电场/原函数)：`#58C4DD` (3B1B Blue C)
- 次物理量 (反向/磁场/翻转核)：`#FC6255` (3B1B Red C)
- 综合量 (合成波/总能量/卷积值)：`#2ED573` (Emerald Green)
- 关键特征/波节/波腹：`#FFFF00` (Yellow)
- 强调外框/重点结论：`#FF9F43` (Orange)

### 2. 经典白板手绘风 (Light Whiteboard)
- 背景底色：`#F8FAFC`（象牙白白板）
- 卡片底色：`rgba(255, 255, 255, 0.92)`，边框 `rgba(15, 23, 42, 0.12)`
- 墨水颜色：`#0F172A` (深炭黑)、`#0284C7` (钴蓝)、`#DC2626` (板书红)

## 二、指示箭头运动连续性标准 (根治取模瞬移)

### 1. 历史缺陷与物理违和
在历史实现中，常采用取模算法计算移动箭头：
```javascript
// 错误做法：导致每隔固定周期瞬间反跳
const shift = (dir * ((t * V) % 120)) - 60;
```
这会导致箭头每隔数帧在画面中央瞬移跳变 120px，极度分散观众注意力，甚至被误读为反向冲击波。

### 2. 标准规范：绝对世界坐标锚点 + 连续相位微光流
1. **世界坐标绝对锚定**：将指示箭头锚定在物理标尺上的固定坐标（如 $-1.75\lambda, -1.25\lambda, -0.75\lambda$）。在世界空间中坐标恒定，**帧间瞬移跳变降为 0.0px (100% 根除)**。
2. **共振呼吸微光**：利用局部相位 $\cos(\omega t - \beta x)$ 调制箭身亮度（$0.72 \sim 1.00$），当波动波峰推进至箭头正下方时，箭头同步泛起柔和光晕。
3. **连续滚动内纹理**：箭身内部填充周期自封闭的细虚线，沿速度方向匀速滚动，清晰指示流动方向，同时由真实曲线承担宏观位移表现。

## 三、教学揭示速度与真实波速解耦

### 1. 常见做坏方式
使用 X 轴线性裁切或扫掠（如 1.0 秒内从左到右铺开 1000px），产生的扫掠边缘移动速度（高达 $1000\text{ px/s}$）远大于物理波速（$250\text{ px/s}$），导致观众误将“画卷展开边缘”当做“电磁波传播速度”。

### 2. 标准规范：稳态场透明度平滑渐入 (Full-Field Alpha Fade-In)
- 从首帧起，波形或场分布就完整覆盖全域坐标；
- 前 $0.5 \sim 1.0$ 秒内仅进行全局透明度渐入（`alpha = MO.smooth(clamp(lt / 0.8))`）；
- 波峰与等相位面从一开始就严格以相速度 $v$ 匀速推进，彻底杜绝虚假波前速度。

## 四、RSA 科技黑板马克笔手绘材质重构

针对深色背景下的手绘板书场景（如镜头 5）：
1. **高对比度象牙白笔杆**：
   - 笔杆采用象牙白/浅银灰（`#F8FAFC`），辅以深色外轮廓线（`#0F172A`）与金属侧阴影，在深色黑板和深色卡片上的对比度达 **$> 10:1$**，轮廓分明。
2. **彩色板书墨水笔尖**：
   - 笔尖颜色严格与绘制的线条墨水颜色一致（如亮橙色 `#FF9F43`），搭配银色金属套箍与高光细线，还原黑板荧光墨水笔真实质感。
3. **防遮挡运笔路径**：
   - 手臂与手掌在完成绘制后，应顺势平滑滑向画外（如左下方），并在画面右侧留出充足空间展示核心公式与深度解析，杜绝遮挡板书文字。
